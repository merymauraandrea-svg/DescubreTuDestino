# 🌎 Descubre tu próximo destino

### Un viaje comienza con una buena recomendación

Este proyecto nace de la idea de combinar el turismo con las nuevas herramientas de inteligencia artificial, buscando una manera sencilla y entretenida de ayudar a los viajeros a descubrir destinos de Chile según sus intereses.

Fue desarrollado como parte de una actividad académica de inteligencia artificial, utilizando **GitHub Copilot** como apoyo para generar código en Python.

## 🌸 ¿De qué trata nuestro proyecto?

**Descubre tu próximo destino** es un sistema básico de recomendaciones turísticas que permite a los usuarios elegir qué tipo de experiencia les gustaría vivir.

El programa ofrece cinco categorías:

- Naturaleza
- Aventura
- Gastronomía
- Cultura
- Relajación

Según la opción seleccionada, el sistema muestra destinos turísticos de Chile acompañados de una breve descripción.

## 💻 ¿Cómo desarrollamos nuestra idea?

**1. Preparación del entorno**

Instalamos Visual Studio Code, Git y Python para contar con las herramientas necesarias para desarrollar el proyecto.

**2. Utilización de GitHub Copilot**

Conectamos nuestra cuenta de GitHub a Visual Studio Code y utilizamos GitHub Copilot para generar el código inicial del sistema.

Le solicitamos crear un programa de recomendaciones turísticas utilizando funciones, condiciones y descripciones de destinos chilenos.

**3. Creación del programa**

Creamos el archivo `recommendation_system.py`, que contiene la información de los destinos y permite seleccionar diferentes intereses turísticos.

**4. Prueba de funcionamiento**

Ejecutamos el programa desde la terminal de Visual Studio Code.

Seleccionamos la opción 3, correspondiente a gastronomía, y el sistema recomendó Valparaíso y el Valle del Elqui.

La prueba finalizó correctamente.

## ✨ ¿Qué aprendimos?

Esta actividad nos permitió conocer de manera práctica cómo la inteligencia artificial puede apoyar el desarrollo de soluciones tecnológicas.

También comprendimos que herramientas como GitHub Copilot pueden facilitar la programación, incluso cuando estamos comenzando a aprender.

Desde la perspectiva de la Gestión Turística, este tipo de soluciones podría contribuir a personalizar las experiencias de los viajeros y facilitar el descubrimiento de nuevos destinos.

## 🌷 Reflexión final

La tecnología está transformando la manera en que las personas planifican sus viajes. A través de este proyecto pudimos experimentar cómo una idea sencilla puede convertirse en una herramienta funcional con el apoyo de la inteligencia artificial.

Aunque nuestro sistema es una primera versión, representa una oportunidad para seguir explorando nuevas formas de conectar a los viajeros con los destinos turísticos de Chile.
